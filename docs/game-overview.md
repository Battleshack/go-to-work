# Corporate Ladder Game Overview

## Game Concept
The Corporate Ladder is an incremental game that simulates career progression in a corporate environment. Players start from entry-level positions and work their way up through the corporate hierarchy through strategic decisions, skill development, and task completion.

## Core Game Elements

### Player Stats
- **Level**: Player's career level, starting at 1
- **Money**: Salary-based currency (Initial: $50,000)
- **Points**: Achievement-based progression metric
- **Tasks**: Number of completed work tasks
- **Experience**: Progress towards next level
- **Current Position**: Player's role in the organization

### Game Mechanics
1. **Career Progression**
   - Experience-based leveling system
   - Position-based salary progression
   - Task completion tracking
   - Strategic lateral and vertical movements

2. **Economy System**
   - Salary-based income
   - Performance-based points
   - Upgrade purchases for progression
   - Lateral move bonuses (10% salary increase)

3. **Upgrade System**
   - Click Power: Increases points per action
   - Auto-Clicker: Enables passive point generation
   - Multiplier: Enhances overall earnings
   - Upgrades unlock based on player level
     - Auto-Clicker unlocks at level 3
     - Multiplier unlocks at level 5

## Visual Design
The game features a modern, corporate-themed interface with:
- Teal-based color scheme (#0F5057, #0FB0C1)
- Accent colors for different elements:
  - Red (#FF522E) for emphasis
  - Green (#46C97D) for success/money
  - Yellow (#F0F557) for points/warnings
- Professional typography with Jaro font family
- Clean, modern UI components with consistent styling
