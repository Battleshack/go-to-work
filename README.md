# Corporate Ladder Game

An incremental game where players climb the corporate ladder from intern to CEO. Navigate through corporate politics, gain experience, and make strategic career moves in this modern corporate simulation.

## 🎮 Features

- **Career Progression**: Start as an intern and work your way up through 15 unique corporate levels
- **Organizational Structure**: Navigate through a realistic corporate hierarchy:
  - Corporation
  - Division
  - Department
  - Section
  - Team
- **Skill-based Movement**: Strategic lateral and vertical movements based on skill compatibility
- **Upgrade System**: 
  - Auto-clickers for passive income
  - Multipliers to boost your earnings
  - Position-based salary progression

## 🚀 Getting Started

### Prerequisites

- Node.js (16.x or higher)
- npm or yarn

### Installation

1. Clone the repository:
```bash
git clone https://github.com/Battleshack/go-to-work.git
cd go-to-work
```

2. Install dependencies:
```bash
npm install
# or
yarn install
```

3. Run the development server:
```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## 📊 Game Mechanics

### Level System
- Experience points based progression
- Each level unlocks new opportunities and challenges
- Unique position descriptions and responsibilities

### Organization Structure
- Complex corporate hierarchy system
- Skill gap calculations for position transitions
- Strategic career path planning

### Economy
- Position-based salary system
- Upgrade purchases for progression
- Auto-clickers for passive income
